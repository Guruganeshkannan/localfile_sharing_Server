## ✨ Features  

✔️ **Drag & Drop File Uploads** – Simply drag files into the browser to upload.  
✔️ **Upload Progress Bar** – See real-time upload progress.  
✔️ **Instant File Download** – Click on a file to download it.  
✔️ **No Page Reload** – Uploads and updates happen dynamically.  
✔️ **Minimalist & User-Friendly UI** – Clean and easy to use.  
✔️ **Runs on Local Network** – No internet required.

## 🚀 How It Works  

1️⃣ Drag and drop files into the upload area.  
2️⃣ Track real-time progress while the file uploads.  
3️⃣ Files appear instantly in the download list.  
4️⃣ Click on a file to download it to your device.
